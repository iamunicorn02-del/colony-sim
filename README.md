Создать тип City:
type City = {
  id: string;
  name: string;
  x: number;
  y: number;
  population: number;
};

При генерации мира автоматически создавать от 5 до 15 городов. (Надо добавить конфигирируемую переменную пока что захардкоженную)

Город может появиться только на тайле типа GRASS.
Город не может появиться: на воде, ближе чем на 10 тайлов к другому городу.

Для размещения города использовать случайный поиск подходящих координат.

Вернуть массив городов вместе с данными мира.

На Canvas отображать города отдельным маркером поверх тайлов.
При клике по городу выводить его данные:
название;
координаты;
население. ( все кроме координат пока что рандомное)
